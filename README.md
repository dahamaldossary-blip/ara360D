مشروع: عرض KML محلي باستخدام Cesium

الملفات:
- index.html    -> الصفحة الرئيسية (افتحها في متصفح)
- data.kml      -> ملف KML الذي زودته

كيفية الاستخدام:
1) افتح index.html في متصفح يدعم WebGL (Chrome/Firefox/Edge).
2) ضع توكن Cesium Ion في الحقل العلوي (يمكنك الحصول عليه من: https://cesium.com/ion/tokens).
3) اضغط "تحميل وفتح KML".
4) ستظهر الخريطة وسيتم عرض محتويات KML.

ملاحظة مهمة:
- الصفحة تستخدم Cesium من CDN. لتشغيلها بدون إنترنت تحتاج إلى تنزيل مكتبة Cesium محليًا أو تشغيل خادم محلي مع ملفات Cesium.
